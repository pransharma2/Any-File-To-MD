Privacy Policy

Last updated 14 November 2026

Any File To MD is built so that your documents never leave your computer. There are no accounts, no analytics and no tracking.

What the app collects

Nothing. The app does not collect, store or transmit personal information, usage data or file contents.

Where your files go

Files are read from your source folder and written to the output folder you choose, both on your own disk. The built-in server only listens on 127.0.0.1, rejects requests addressed to any other host, and requires a random token generated each time the app starts.

Network access

The first launch downloads the uv helper, Python and the converter packages. After that, the app works fully offline. Conversions never contact an external service, and no API keys are used.

Cookies and storage

The app sets no cookies and keeps no history of folders or files between sessions.
